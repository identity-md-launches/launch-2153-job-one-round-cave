# The Opened Seeds

Added [Field Change](tools/field-change/README.md), an offline packed-field
comparison between two proof-verified endpoint states linked to one explicitly
trusted tip hash. A separately retained normalized-layout fingerprint binds
the worker's reviewed field assumptions. It reports signed endpoint deltas,
unnamed-bit changes, storage existence, account code-hash changes and the
separate overall storage commitment. It uses the existing cryptographic
verifiers unchanged and needs only Python's standard library.

```sh
python3 -B line-2/tools/field-change/field_change.py demo
```
